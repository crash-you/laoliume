## 二、如果是 Codex Reset（重置卡），它到底是什么？

这个地方很多人容易搞混。

假如你的邀请奖励写的是 **Codex Reset**

打开：**设置 → 用量**

可能会看到：**1 reset available**

也就是有一次重置可以使用。

![二、如果是 Codex Reset（重置卡），它到底是什么？，原文配图 10](/images/codex-quota-top-up/image-10.png)

需要的时候点一下。

它会刷新你的 **5 小时用量周期和每周用量周期**。

但有个地方一定注意。

**使用 Reset 以后，你原来的每周重置日期也会发生变化。** 

所以如果你的额度还有很多，别看到有 Reset 就手欠直接点掉。

等真的快没额度的时候再用。

另外，邀请活动的奖励一般也有有效期。

具体什么时候过期，直接看你自己的活动页面。

## 四、第二种，直接从 OpenAI 官方购买

现在 Codex 额度用完以后，OpenAI 已经支持直接续了，也就是俗称的 credits

### Credits 是什么？

Credits 可以理解成按量付费的额外额度。

正常情况下，Codex 会先使用你套餐本身包含的额度。

套餐额度达到限制以后，再开始从你购买的 Credits 余额里扣。

可以打开：**ChatGPT → 添加额度**找到

![Credits 是什么？，原文配图 12](/images/codex-quota-top-up/image-12.png)

如果有，就可以直接购买。

![Credits 是什么？，原文配图 13](/images/codex-quota-top-up/image-13.png)

不过 Credits 有个很容易搞混的地方。

**它和 API Credits 不是一个东西。**

这是 ChatGPT / Codex 这一套产品里的使用额度，不能拿去当 OpenAI API 余额使用。

Codex 最近的额度规则变化挺快。
