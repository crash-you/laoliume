大家好，我是佬刘。

最近加我的人多了以后，我发现很多人虽然已经在用 ChatGPT，但还是分不清 **ChatGPT、Plus、Pro、Codex** 到底是什么。

有人问我：买了ChatGPT Plus，是不是就可以买Codex？

也有人发现，自己的ChatGPT明明还能聊天，Codex却提示额度不够了。

还有人把ChatGPT Pro、GPT-6 Pro、Codex当成同一个东西。

这几个名字放在一起，确实很容易乱。

所以这篇我不讲复杂的，直接把 ChatGPT Plus、Pro、Codex，以及大家最关心的 Codex 额度，一次讲清楚。

## 一、先把 ChatGPT、Plus、Pro、Codex 分开

先记住这几个关系。

**ChatGPT 是产品。**

你现在打开网页或者 App，和 AI 聊天、上传文件、生成图片、做 Deep Research，用的都是 ChatGPT。

![ChatGPT 网页端对话界面](/images/chatgpt-plus-pro-codex/image-1.png)

**Plus 和 Pro 是 ChatGPT 的会员套餐。**

你花钱购买的不是一个更高级的 ChatGPT，而是一套会员权益，包括更多模型、更高的使用额度，以及 Codex、Deep Research 等功能的使用权限。

![ChatGPT Go、Plus、Pro 套餐价格与权益对比页面](/images/chatgpt-plus-pro-codex/image-2.png)

**GPT-5.6、GPT-6 Astra 这些是模型。**

可以把模型理解成 AI 的大脑。

不同模型的能力、速度和额度消耗都不一样。

![ChatGPT 模型选择列表，含 GPT-6 Astra、GPT-5.6 Sol 等](/images/chatgpt-plus-pro-codex/image-3.png)

**Codex 是 OpenAI 的 AI 编程 Agent。**

它可以读取项目、操作电脑、跑测试等。

所以这四个东西放在一起，大概是这样的：

![ChatGPT 产品与各档会员套餐关系示意图](/images/chatgpt-plus-pro-codex/image-4.png)

只要把这张关系图看懂，后面就简单了。

OpenAI 当前已经把 Codex 包含在 ChatGPT 各档套餐中，包括 Free、Go、Plus 和 Pro，只是各套餐能用的额度不同。

ChatGPT Pro 是会员。

GPT-6 Pro、GPT-5.6 Sol Pro 是模型档位。

虽然都带一个 Pro，但不是一个东西。

## 二、ChatGPT Plus是什么？

Plus 是目前很多个人用户选择的套餐。

官方价格是：**20 美元/月。**

相比免费版，Plus 会提供更多模型和工具权限、更高的消息额度、文件上传、图片生成、Deep Research，以及更高的 Codex 使用额度。

![ChatGPT Plus 每月 20 美元套餐权益说明页面](/images/chatgpt-plus-pro-codex/image-5.png)

另外要注意一个问题。

**ChatGPT Plus 不包含 API 额度。**

你买了 Plus，不代表 OpenAI API 可以免费调用。

ChatGPT 会员和 API 是两套计费体系，这个也是很多新用户容易混淆的地方。

如果你平时就是用 ChatGPT 聊天、生成图片、上传文件，偶尔再让 Codex 写代码，Plus 基本已经覆盖了这些需求。

## 三、ChatGPT Pro是什么？

Pro 可以理解成 Plus 上面的高额度套餐。

目前个人 Pro 有两个档位：

**100 美元/月**和**200 美元/月，**也简称为 5x ， 20x

![ChatGPT Pro 每月 100 美元套餐权益说明页面](/images/chatgpt-plus-pro-codex/image-6.png)

![ChatGPT Pro 每月 200 美元套餐权益说明页面](/images/chatgpt-plus-pro-codex/image-7.png)

其中 100 美元 Pro 的标准 Codex 使用量大约是 Plus 的 **5 倍**，200 美元 Pro 大约是 Plus 的 **20 倍**。

这里的重点是：**Pro 买的主要是更高的使用上限，和更全面的记忆和背景信息，以及 Pro 模型。**

还可以使用由 GPT-6 Astra 驱动的 **GPT-6 Pro**。

用的多了，你就会发现，一个能记住你的AI的惊喜之处，它可能在你对话的某一句里，突然提醒你5天前你说了什么内容。

你一天只和 ChatGPT 聊几十句话，偶尔让 Codex 改个项目，那么 Pro 的额度可能根本用不上，但如果你每天都让 Codex 跑项目、读大量代码、执行长任务，Plus 的 Codex 额度就容易限额。

这时候才可以考虑选择Pro。

## 四、Codex到底是什么？

我之前写 Codex 比较多，所以很多人是看 Codex 教程加到我的。

但还有不少人以为：Codex 就是 ChatGPT 里的一个模型。

这个理解不太对。

**Codex 是一个编程 Agent。**

模型只是它工作时调用的大脑。

比如你打开一个项目以后，可以直接告诉 Codex：

```Plain Text
读取这个项目。

先分析当前代码结构和功能。

找到登录模块存在的问题。

修改代码后运行测试。

测试通过以后告诉我修改了哪些文件。
```

![Codex 编程 Agent 对话界面](/images/chatgpt-plus-pro-codex/image-8.png)

Codex 可以自己读文件、改代码、执行命令，再根据执行结果继续工作。

![Codex 读取项目、修改代码并执行命令的过程](/images/chatgpt-plus-pro-codex/image-9.png)

所以 ChatGPT 和 Codex 的使用场景也有区别。

ChatGPT 更像一个通用 AI 助手。

Codex 更偏向让 AI 进入一个真实的项目环境里完成任务。

![ChatGPT 通用助手与 Codex 编程 Agent 的定位区别示意图](/images/chatgpt-plus-pro-codex/image-10.png)

## 五、买了Plus，可以直接用Codex吗？

可以！

现在 Codex 已经包含在 ChatGPT 套餐中。

你安装Codex App（现在codex与chatgpt合并进一个软件：ChatGPT），或者使用 Codex CLI 时，登录自己的 ChatGPT 账号，就会读取当前账户对应的套餐权益。

如果你是 Plus，就是 Plus 对应的 Codex 用量；如果你是 Pro，就是 Pro 对应的 Codex 用量。

不需要购买第二份会员。

不过这里有一个例外。

如果你在 Codex 里不用 ChatGPT 账户登录，而是自己配置OpenAI API Key，那么走的就是 API 计费。

![Codex 已包含在 ChatGPT 各档套餐中的说明示意图](/images/chatgpt-plus-pro-codex/image-11.png)

## 六、ChatGPT还有额度，为什么Codex已经不能用了？

这个问题我最近被问得很多。

因为：**ChatGPT普通聊天额度和Codex使用额度，不是一套额度。**

Codex额度可在chatGPT主页面，点击左下角头像，点击设置，找到使用情况查看额度。

![ChatGPT 设置中的使用情况页面，可查看 Codex 额度](/images/chatgpt-plus-pro-codex/image-12.png)

在 ChatGPT 里和模型聊天，走的是 Chat 的使用限制。

而chat模型，几乎无限制次数

Codex 和 ChatGPT Work这一类 Agent 功能，则有自己的 Agent 用量池。

所以会出现一种很正常的情况：

打开 ChatGPT，还能继续问问题；但你打开 Codex，已经提示使用额度不足。

反过来也不要用ChatGPT还能不能聊天来判断 Codex 剩多少额度。

OpenAI 当前明确把普通 Chat 与 Work/Codex 的使用量分开计算，而 Work 和 Codex 会共享 Agent 用量。

这两个东西一定要分开。

## 七、Plus的Codex额度到底是多少？

这也是最难回答的问题。

因为 Codex 现在不是简单按照一句话扣一次额度来计算。

同样发送一句话：

```Plain Text
帮我改一下按钮颜色。
```

和：

```Plain Text
读取整个项目，重构登录系统，修改数据库结构，运行全部测试并修复问题。
```

消耗当然不可能一样。

Codex 的实际消耗会受到模型、任务复杂度、上下文长度、推理强度等因素影响。

所以官方给出的也是一个**估算区间**。

它只是官方根据典型任务给出的估算。

而且 Codex 除了 5 小时窗口之外，还有周额度限制。

所以不要看到 Plus 的 Astra 是 5–45 次

就理解成自己一定可以发送 45 条。

你跑一个很大的项目，读几十个文件，开高推理强度，可能几次任务就没啦！

## 八、为什么GPT-6 Astra的Codex额度掉这么快？

看上面的表格应该就能发现了。

同一个 Plus 套餐，不同模型能完成的任务量差距很大。

GPT-6 Astra 是当前能力更强、计算成本更高的一档模型，因此同样的 Codex 套餐，用 Astra 跑长任务时，用量下降会更快。

OpenAI 官方也专门提醒，Astra 的额度消耗速度可能高于 GPT-5.6 Sol。

所以我现在用 Codex，不会所有任务都上Astra Ultra，大部分用的都是 Astra XHigh。

简单的任务可以交给成本更低的模型。

模型越强，不代表每一个任务都值得用它。

## 九、Codex额度在哪里看？

如果你发现 Codex开始提示额度不足，可以先去看自己的 Usage。

在 Codex 或 ChatGPT 的相关设置里，可以看到：

当前用量、剩余额度以及下一次重置时间。

![ChatGPT 使用情况页面，显示剩余额度与下一次重置时间](/images/chatgpt-plus-pro-codex/image-13.png)

如果你使用 Codex CLI，可以输入：

```Plain Text
/status
```

查看当前会话对应的使用状态。

![Codex CLI 中执行 /status 查看当前会话与用量](/images/chatgpt-plus-pro-codex/image-14.png)

所以以后不要再靠感觉猜：我今天也没用几次，怎么就没了？然后开始喷chatgpt - -

先看 Usage，Codex 算的是任务消耗，不是你肉眼看到的聊天条数。

另外，在前几天的一次更新后，Plus 用户又把新的 5小时限额给加上去了，而Pro用户则无5小时限额限制

![Codex 界面显示 5 小时与每周额度限制](/images/chatgpt-plus-pro-codex/image-15.png)

![Pro 账号菜单中的使用情况与邀请好友入口](/images/chatgpt-plus-pro-codex/image-16.png)

## 十、Codex额度用完怎么办？

目前有几个选择。

最简单的就是等待额度重置。

如果你还没有完全撞到限额，也可以把日常任务切到成本更低的模型，让剩余额度用得更久。

另外，OpenAI 现在也支持符合条件的 Plus 和 Pro 用户单独购买 Credits。

![Plus 与 Pro 账号的 Credits 余额及购买入口](/images/chatgpt-plus-pro-codex/image-17.png)

也就是说：

**Codex额度用完以后，不一定非要把Plus升级成Pro。**

如果你只是这个月偶尔有几天任务很多，可以购买额外额度继续使用。

套餐自带的使用量会先消耗，用完以后，再开始扣你购买的 Credits。

对于平时 Codex 用得不多，只是偶尔跑一次大项目的人，这种方式可能比长期升级 Pro 更合适。

## 十一、Plus和Pro到底怎么选？

如果你现在主要使用 ChatGPT，平时聊天、写东西、生成图片、上传文件，再偶尔使用 Codex。

我更建议从 **Plus** 开始，已经可以覆盖大部分个人用户的 AI 使用场景。

如果你已经开始每天使用 Codex，而且经常跑长任务，一周能撞几次额度，那么可以考虑** 5x Pro**。

如果 Codex 已经变成你的主要生产工具，一天大部分时间都有项目在运行，才有必要考虑 **20x Pro**。

补充一点，如果你想要一个可以记住你10天之前说过的内容的贾维斯，可以尝试一下pro！！
