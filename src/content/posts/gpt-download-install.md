大家好，我是佬刘。

先说结论：

**大家现在要下载的官方桌面程序，名字叫 ChatGPT。**

很多人平时习惯说 下载 GPT ，但真正进入官网以后，看到的应用名称是 ChatGPT。

这篇只讲下载和安装：从哪里下载、Windows 怎么装、macOS 怎么装、装完以后怎么打开和登录。

## 一、下载前先把名字搞清楚

GPT 是大家习惯使用的简称，真正安装到电脑里的产品叫 ChatGPT。

现在同一个桌面应用里，可以使用 ChatGPT，也可以按需要切换到 Codex。

所以，看到应用名称是 ChatGPT，不代表你下错了。

## 二、到底去哪里下载？

官方入口：[https://learn.chatgpt.com/zh-Hans/docs/app](https://learn.chatgpt.com/zh-Hans/docs/app)

官方页面目前提供 macOS、Windows 和 Linux 桌面版，请根据自己的电脑系统选择。

![ChatGPT 官方下载页面](/images/gpt-download-install/image-1.png)

这里我多提醒一句：

**认准 ChatGPT 官方页面，不要从不明软件下载站随便找安装包。**

## 三、Windows 怎么下载安装？

这一块很多教程只写一句 点击下载 ，然后就结束了。

但问题是**下载不等于安装。**

### 点击 下载 Windows 版

在官方下载页面选择 Windows 版，浏览器会获取官方安装器。

打开刚刚下载的安装器。安装过程中，页面可能直接开始安装，也可能调用 Microsoft Store 组件，这都属于正常流程。

### 在 Microsoft Store 确认应用

![Microsoft Store 中的 ChatGPT 应用](/images/gpt-download-install/image-2.png)

这里看两个地方：

**应用名称是 ChatGPT。**

**发布者是 OpenAI。**

确认没问题以后，点击页面里的 下载 或 安装 ，然后等待系统处理完成。

### 看到 打开 才算安装完成

![安装完成后出现打开按钮](/images/gpt-download-install/image-3.png)

只有页面显示 已安装最新版本 ，并出现 打开 按钮，才说明安装真的完成了。

点击 打开 ，ChatGPT 桌面应用就会启动。

**Windows 的完整流程就是：**

**进入官网 → 下载安装器 → 打开安装器 → 等待安装完成 → 点击打开。**

### Microsoft Store 打不开怎么办？

可以先关闭页面，再从 ChatGPT 官方入口重新进入。

如果你熟悉命令行，OpenAI 官方文档还提供了这条 Windows 安装命令：

```
winget install --id 9PLM9XGG6VKS -s msstore
```

不熟悉命令行的话，不用折腾这一步，直接走官方下载页面更简单。

## 四、macOS 怎么安装？

macOS 也从同一个官方页面进入。

当前页面上的 macOS 下载入口标注的是 Apple 芯片版。点击下载后，打开下载文件，按照 macOS 的安装提示把 ChatGPT 放进 应用程序 。

复制完成后，从 应用程序 或 Launchpad 打开 ChatGPT。第一次启动时如果系统弹出安全确认，先确认文件来自 OpenAI 官方页面，再继续打开。

如果你的 Mac 使用 Intel 芯片，不要强行套用 Apple 芯片版。可以先用网页版，再以官方页面后续提供的版本为准。

## 五、安装完以后怎么登录？

Windows 和 macOS 安装完成后的登录流程基本一样。

第一次打开 ChatGPT，会看到登录页面。

![ChatGPT 登录页面](/images/gpt-download-install/image-4.png)

点击 继续登录 ，系统会打开浏览器进入官方登录页面。

如果浏览器里已经登录 ChatGPT，页面可能直接让你选择工作空间。个人使用就选择 个人账户 ，然后点击 继续 。

![选择工作空间](/images/gpt-download-install/image-5.png)

授权完成以后，浏览器会询问是否打开 ChatGPT。

![浏览器询问是否打开 ChatGPT](/images/gpt-download-install/image-6.png)

点击 打开 ChatGPT ，系统会自动回到桌面应用。

![ChatGPT 桌面应用主页面](/images/gpt-download-install/image-7.png)

进入主页面以后，下载、安装和登录才算全部走完。

最后一张截图显示的是 Codex 页面，这是同一个 ChatGPT 桌面应用里的工作入口，并不是安装了另一个软件。

## 六、几个常见问题

### 安装器下载了，为什么电脑里找不到 ChatGPT？

大概率是你只完成了下载，还没有打开安装器。找到浏览器下载列表里的安装器，双击运行，再等到页面出现 已安装最新版本 和 打开 。

### 登录完成后，为什么还停在浏览器？

看一下浏览器有没有 要打开 ChatGPT 吗 的提示。点击 打开 ChatGPT ，登录结果才会交回桌面应用。

### 不安装桌面版，能不能直接用？

可以。打开 [https://chatgpt.com/](https://chatgpt.com/)，登录以后就能使用网页版。

## 七、最后总结一下

**整个流程其实就 6 步：**

**进入 ChatGPT 官方下载页 → 选择电脑系统 → 打开安装器 → 等待安装完成 → 打开 ChatGPT → 在浏览器中登录。**

Windows 用户要记住，下载按钮点完不代表安装完成。看到 打开 按钮，才算真正装好。
