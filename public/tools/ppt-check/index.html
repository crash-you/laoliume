BEFORE YOU GO

几个需要说明的地方

文件会上传吗？

不会。你选中的 PPTX 在当前浏览器内解压和检查；检查器没有文件上传接口，也不调用外部 AI。示例按钮会下载本站的公开示例文件。导出的报告含文件名和结构统计，请按需要保管。

能直接把图片转换成可编辑 PPT 吗？

这个工具只做结构检查。图片的文字识别、版式重建和逐页校对属于另一项工作。它不能自动恢复照片、复杂图表的原始数据或未知公式。

报告说发现原生对象，就一定可以改吗？

不一定。原生对象可能被遮挡、锁定或组织得不方便编辑；报告也不会判断文字识别准确性和视觉还原程度。请实际修改内容、保存并重新打开完成验收。

检查依据和已知限制是什么？

工具读取 PPTX 的 OOXML 对象结构和关系文件，识别文字、图片、表格、图表等类型，不运行文件内容。复杂对象和母版继承需要人工复核。参考 Microsoft PresentationML 文档。
